# Mithibai Admission Portal

A web-based document verification system built to digitise 
the manual admission process at Mithibai College, Mumbai.

## Problem
College admissions involve manual document verification — 
slow, error-prone, and paper-heavy. This project aimed to 
digitise and automate that process online.

## Features (Built)
- Document upload system (Aadhaar PDF etc.)
- AWS S3 bucket integration for secure file storage
- GraphQL API layer
- Next.js frontend

## Planned Features
- Node.js + Express backend
- Admin verification dashboard
- Automated document validation

## Tech Stack
- **Frontend:** Next.js
- **API:** GraphQL
- **Storage:** AWS S3
- **Backend (planned):** Node.js, Express
